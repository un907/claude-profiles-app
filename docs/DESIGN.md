# UI / UX design

## アプリの仕事

利用者が、目的のClaudeを1回で起動・表示でき、同じ場所から日常的なプロフィール管理まで完結できること。

## 情報の優先順位

1. プロファイル名
2. 起動状態と次に起きる操作
3. 用途と標準プロファイルの区別
4. 追加・一括起動
5. 編集・終了・再起動は行の管理メニューへ集約
6. アーカイブと設定は左サイドバーで通常操作から分離

## Layout

管理画面はmacOS標準のNavigationSplitViewで構成します。

- 左: プロフィール／アーカイブ／設定と常時ステータス
- 右: 標準ListまたはFormで選択した仕事だけを表示
- 上: 追加・一括起動を標準Toolbarへ配置
- 危険操作: 行の管理メニューと確認ダイアログの二段階
- アーカイブ: データ削除ではなく、メイン一覧からの退避と復元
- メニューバー: 標準MenuBarExtraから起動・表示し、管理画面は独立ウィンドウで開く

## Visual language

- **System background**: macOSのウィンドウ外観へ自動追従
- **Primary / Secondary**: システムの意味色でライト・ダーク双方の可読性を維持
- **Accent**: 利用者が選んだmacOSのアクセントカラーを標準選択状態へ反映
- **Profile color**: 各プロフィールの識別と起動・表示ボタンだけに使用
- **Status**: システムのgreen／secondaryで起動状態を表示

固有表現は、プロフィール行の左端に置く細い識別色。装飾面は追加せず、複数のClaudeを見分ける仕事だけを担います。

macOS 26以降では、標準Window・Toolbar・Sidebar・MenuBarExtraにOS自身がLiquid Glassを適用します。プロフィール操作だけは標準glassProminentボタンを使い、独自のガラス面は描画しません。macOS 13〜15では標準borderedProminentへフォールバックします。

## Motion

選択、行の追加・削除、シート、メニューはmacOS標準トランジションへ委ねます。独自の移動・拡縮・ホバーアニメーションは追加しません。色だけに依存せず、状態文言と操作名を必ず併記します。

## 共有する設定の拡張

標準プロフィールから共有する項目は、Claude Codeの標準的な設定に限った組み込みの一覧です。利用者が独自に置いたファイルやフォルダも共有したい場合は、`~/Library/Application Support/Claude Profiles Launcher/extra-shared-items.txt`に1行1項目で名前を書きます。`#`で始まる行と空行は無視し、`/`や`..`を含む名前と`.`は設定フォルダの外や設定フォルダ全体を指すため無視して警告をログに残します。ファイルは起動準備のたびに読み直すので、アプリの再起動は不要です。一覧から外れた項目について、既に作成済みのリンクは削除せずそのまま残します。

## ターミナル用コマンド

追加プロフィールには、`claude-`に続く名前でターミナル用コマンドを設定できます。編集シートでは固定文字`claude-`の右に標準のテキストフィールドを置き、使えない名前や重複した名前の時は保存ボタンを無効にして、理由をフィールドの下に表示します。カードには設定済みの時だけコマンド名を小さく表示し、色付けはしません。実体は`~/.local/bin`に生成するシェルスクリプトで、保存・名前変更・アーカイブ・復元・アプリ起動のたびに全体を照合して一致させます。所有マーカーの行がないファイルは利用者のものとして扱い、上書きも削除もしません。
